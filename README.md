# Agentic Coding with Shiny and Positron

Welcome to the **agentic-coding-shiny-positron** repository! This project explores AI-assisted (agentic) coding workflows for building data applications, specifically focusing on R, Shiny, and Posit's new IDE, Positron.

## 📁 Repository Contents

This repository contains the following key files:

*   **`app.R`**: The main R script containing the logic and UI for the Shiny application.
*   **`tourism-mockup.qmd`**: A Quarto markdown file serving as a design mockup, data exploration, and reproducible document for a tourism-focused project.
*   **`tourism-mockup.html`**: The compiled HTML output of the Quarto mockup, ready for viewing in a web browser.

## 🚀 Getting Started

### Prerequisites

To run and edit the files in this project, you will need:
*   [R](https://cran.r-project.org/) installed on your machine.
*   [Positron IDE](https://github.com/posit-dev/positron) (or RStudio).
*   Required R packages (e.g., `shiny`, `rmarkdown`, `quarto`). You can typically install the core requirements via:
    ```R
    install.packages(c("shiny", "rmarkdown"))
    ```
